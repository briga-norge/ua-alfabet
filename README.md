# Ukrainian Alphabet Interactive Activity

Standalone HTML version prepared for GitHub Pages and Wix embedding.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Source: Deploy from a branch.
5. Select Branch: main and Folder: /root, then Save.
6. After deployment, open the GitHub Pages URL and embed it in Wix.

## Wix iframe example

```html
<iframe
  src="https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/"
  width="100%"
  height="900"
  style="border:0; border-radius:16px; overflow:hidden;"
  allow="autoplay"
  loading="lazy">
</iframe>
```
